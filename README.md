# Blackwell & Unavowed – Deutsche Fan-Übersetzungen

Inoffizielle deutsche Übersetzungen für die Adventures von **Wadjet Eye Games**:

| Paket | Spiele |
|---|---|
| `Blackwell_Deutsch_2026-11-15.zip` | Blackwell Legacy, Unbound, Convergence, Deception, Epiphany |
| `Unavowed_Deutsch_2026-11-15.zip` | Unavowed |

**➡ Download: [Releases](../../releases/latest)**

Jedes Paket enthält pro Spiel einen Ordner `Deutsch-Patch` mit der Übersetzung (`Deutsch.tra`),
Schriften mit Umlauten und ß sowie Installations- und Deinstallationsskripten für Windows und Linux / Steam Deck.
Die Sprachausgabe bleibt englisch, mit deutschen Untertiteln.

## Installation

1. Spielordner öffnen (Steam: Rechtsklick auf das Spiel › *Verwalten* › *Lokale Dateien durchsuchen*).
2. Den Ordner `Deutsch-Patch` des **passenden** Spiels hineinkopieren.
3. **Windows:** `install.bat` doppelklicken, danach in `winsetup.exe` die Sprache **Deutsch** wählen.
   **Linux / Steam Deck:** im Ordner `Deutsch-Patch` `sh install.sh` ausführen.
4. Spiel starten.

Deinstallation: `uninstall.bat` bzw. `sh uninstall.sh`. Ersetzte Dateien werden vorher in `Deutsch-backup` gesichert.
Ausführliche Anleitung: `ANLEITUNG.txt` im Paket.

> **Wichtig:** Blackwell Unbound und Blackwell Convergence haben intern dieselbe Spielkennung.
> Jeden Patch nur in den Ordner des richtigen Spiels installieren.

## Voraussetzung

Die aktuelle Steam-Version des jeweiligen Spiels. Die Pakete enthalten keine Spieldaten.
